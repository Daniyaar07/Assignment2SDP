# Assignment 2
## Project

This project is a delivery application in Java

The user can choose:
- Delivery mode: Road or Sea
- UI platform: Windows or MacOS

## Project Structure
- factorymethod
- abstractfactory
- app
- Main.java

Factory Method is used to create transport
Abstract Factory is used to create UI components

## Example
Road + Windows
Truck delivers Equipment to Astana
